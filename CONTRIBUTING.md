# Contributing

We welcome pull requests from everyone. You are welcome to modify the software
under its applicable licenses, including for your own projects.

1. Open an issue for a substantial proposed change, or send a focused pull request.
2. Develop in the matching PureDesktop suite workspace; keep the app's existing identity and integration contracts.
3. Run the relevant checks listed in `package.json` and the README. Explain what you changed, why, and how you checked it.
4. Preserve upstream copyright, attribution, and license notices. Identify any new dependency and its license.

Contributions are provided under the applicable license for the files you change.
See the README, LICENSE, and THIRD_PARTY_NOTICES.md. Do not include credentials or private user data.
